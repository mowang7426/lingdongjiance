# 灵动监测 4.90：纯文字紧凑排版与屏幕边界修复

基于 `4e0dcfada3601a47e4061dca66eca8875bff272b`，独立修复分支 `fix/text-fit-4.90`。不修改 main 或 cleanup-remove-120，不恢复任何 120Hz 实验。

## 显示规则
- 网速：`↑1.2K/s ↓2.0M/s`；缺失 `↑-- ↓--`；零 `↑0B/s ↓0B/s`。
- 1024 进制：原始速率 >=1024B/s 使用 K，>=1048576B/s 使用 M。B 显示整数、K/M 一位小数，向下截取显示精度，避免阈值以下误显示 1024B 或 1024K。示例 1048575B/s -> 1023.9K/s；1048576B/s -> 1.0M/s。
- 原字段顺序、单位、CPU/电量标记和 SIM 卡号保持不变，仅纯文字行的 ` · ` 改单空格。其他浮窗模式不变，网速开关默认仍关闭。
- OCR 实际提取截图首行：`©13.6% • 640MHz • 57fps • 32.9°C • -286mA • S1-86dBm`，首行置信度 0.5；截图 1290×233，其余文字识别含噪声，不将 OCR 当作完整视觉确认。

## 边界约束
先使用紧凑串；短内容保留用户字号。按已转换到当前显示方向的屏幕宽度减左右安全边距测量，仅过长行动态缩小字体，最低 8pt。到 8pt 仍过长则字符换行，不用省略号、不默认截掉网速或关键数值。UILabel 实测换行高度，浮窗宽高均约束在逻辑屏幕可用区域内。缩放是显式 UIFont 计算，关闭 UILabel 隐式无限缩小，实时反色 alpha mask 复用同一个 UILabel 的 glyph 绘制。

每次内容/尺寸变化即按同一逻辑边界重新钳制中心，覆盖正在拖动时的刷新；锁定位置使用原有边距锚点解析，安全修正不改写持久化锚点。原有旋转/安全区域更新与左右预设继续工作。无新增定时器，网速接口筛选、计数器重置处理、屏幕可见/解锁/纯文字开关采样门控不变。

## 极端限制与验证
全部常规指标开启时可在 8pt 下换行保留数值。若注入的异常数字文本长到占满整个屏幕高度，仍优先保证浮窗边界不溢出，超过可用高度的内容无法同时完整展示；不会为此缩成无限小字。应减少项目或修正异常数据。这是非常规极端输入的限制，不是日常截断方案。

新增原生单位阈值/相邻浮点值测试，以及宽度、字体下限、超长/全部项目模型、横竖屏安全边距、左右/上下锁定、越界拖拽与旋转往返测试。连线测试覆盖生产 UILabel 自动换行与即时边界钳制，原有回归和 no120/打包验证继续运行。C 策略模型与源码连线检查不等同于真机 UIKit 渲染验证。

真机仍需复验：最窄屏全部项目开启；8/13/24pt；两侧锚点/拖拽中刷新/锁定再旋转；横屏左右及倒置；大刘海侧边距；固定颜色与实时反色换行；速率变化引起行数变化；锁屏和隐藏时采样暂停。没有声称完成真机视觉或低占用实测。
