# Source provenance and credits

Infinidock 16 Revival is an unofficial community-maintained revival. It is not
an official update from the original author or distributors.

Credits:

- Original Infinidock author: chpwn.
- Original copyright: Copyright (c) 2010-2014, Xuzz Productions, LLC.
- Later public iOS 11+ source fork: subdiox.
- iOS 15/16 rootless revival and maintenance: JaySuen.

This revival was informed by:

- `subdiox/Infinidock`, a 2019 repository containing the legacy implementation
  and the Xuzz Productions BSD-style license notice:
  <https://github.com/subdiox/Infinidock>
- `tomaszpoliszuk/DockController`, used only as a public reference for modern
  SpringBoard class names and rootless build structure:
  <https://github.com/tomaszpoliszuk/DockController>
- Theos rootless documentation:
  <https://theos.dev/docs/rootless>

The modern scrolling implementation in this repository is newly written. It
does not contain binaries or icon artwork from the original paid package, and
it does not copy GPL-licensed DockController implementation code.
