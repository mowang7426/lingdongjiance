# 5.00 — 双行纯文字浮窗与窗口2右边界

基于 4.99 `9016d46cfdb1`，独立分支 `style/dual-text-wrap-edge-5.00`。

## 使用

设置 → 灵动监测 → 纯文字浮窗：
- 窗口1/窗口2的“双行显示”分别独立保存，默认均关闭；第二浮窗仍默认关闭。
- 开启后按 CPU、频率、FPS、电量、温度、电流、SIM1、SIM2、上传、下载顺序，将启用项目分为前半/后半。上传和下载同组；只剩一项或仅网速双方向时只占一行，不制造空行。
- 数值刷新、单位变化与旋转不会改变双行分组；修改显示项目才重新分组。宽度不足时两行使用统一的配置相关字号缩放，不按实时值缩放；间距仍使用本窗口数据间距（-15～12pt）。异常超长数据裁切在固定槽内。
- 关闭双行回到原有按安全宽度自动换行的布局。
- 窗口2解除位置锁定后拖到最右安全边缘，松手保存边缘锚点。旋转、改变字号/双行、重启 SpringBoard 后沿相同安全边缘恢复；位置预设或手动修改偏移仍可替代保存位置。

## 修改范围与原因

- 网速固定槽位从14字符缩至10字符预算（覆盖 `↑1023.9K/s`），避免过大的额外尾部留白。两个方向之间仍只有与其他槽相同的数据 gap。关闭某方向直接删除对应槽，不保留空洞；双方向在单行模式下一起可容纳时整对换行。
- 窗口2使用其真实根视图容器的尺寸和安全区，而不借用窗口1容器；其左右边界不额外增加4pt，允许到实际安全边缘。窗口1维持原有4pt侧边逻辑。
- 旧保存逻辑用 CGFloat/double 锚点偏移严格比较 CFPreferences 的 float32 偏移，重新读取设置后可能因舍入失配而回落旧中心预设。新匹配按 float32 存储域比较，不抹掉显式位置调整。
- 两个独立双行开关接入已有偏好持久化与通知，不新增 timer，不改 FPS 算法、网络采样、温控、电池、内存或普通胶囊模式；无120实验代码修改。
